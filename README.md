# 🚗 Ford Vehicle Catalog & Comparison

## 📌 Overview

This project was developed during the **Ford Enter** program and consists of a responsive web application created to showcase Ford vehicles through an interactive catalog.

Users can browse vehicle information, compare different models, explore featured cars through an image carousel, and contact the company through a built-in contact form.

The project was built using only **HTML**, **CSS**, and **JavaScript**, focusing on front-end development fundamentals and user experience.

---

## ✨ Features

- 🚘 Ford vehicle catalog
- 📊 Vehicle comparison system
- 🎠 Interactive image carousel
- 📝 Contact form
- 📱 Responsive design
- 🎨 Modern and intuitive interface
- ⚡ Dynamic interactions with JavaScript
